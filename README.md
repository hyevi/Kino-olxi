## 📖 О проекте (About)

**Кино Olxi** — это легковесный MVP-агрегатор, который позволяет быстро найти информацию о фильме или сериале через API Кинопоиска и перейти к его просмотру на сторонних бесплатных зеркалах. 

Проект создан с упором на минимализм, скорость и удобство. Здесь нет регистрации, надоедливой рекламы, комментариев и сложных алгоритмов. Только поиск, карточка фильма и кнопки для просмотра. Приложение упаковано в нативный Android-клиент с помощью **Capacitor**.

> ⚠️ **Дисклеймер:** Проект предоставляется «как есть» (as is). Мы не храним видеофайлы и не гарантируем работоспособность сторонних зеркал. Все права на контент принадлежат их правообладателям.

## ✨ Возможности (Features)

### Для пользователей:
- 🔍 **Быстрый поиск:** Интеграция с неофициальным API Кинопоиска (`kinopoisk.dev`).
- 🎞 **Внутренние карточки:** Вся информация о фильме открывается внутри приложения.
- 🚀 **Умные зеркала:** Автоматическая генерация ссылок для просмотра («Убежище», «Зеркало», «CX») на основе ID фильма.
- 🎨 **5 тем оформления:** Тёмная, Светлая, Океан, Закат и Лес (сохраняется в `localStorage`).
- 🔐 **Приватность:** Ваш API-токен и имя сохраняются только на вашем устройстве.
- ✨ **Пасхалки:** Фильм дня, рулетка случайного фильма, секрет при 5 кликах на логотип и Konami-код.
- ✨ **Визуальные эффекты:** Переключаемый дождь из эмодзи (частицы).

### Для разработчиков:
- ⚙️ **Легкая расширяемость:** Конфиг зеркал (`MIRRORS`) вынесен в отдельный массив. Чтобы добавить новое зеркало, достаточно добавить одну строку.
- 📱 **Кроссплатформенность:** Работает как обычный сайт (Express) и как Android-приложение (Capacitor).
- 🤖 **CI/CD из коробки:** GitHub Actions автоматически собирает `.apk` при каждом пуше в ветку `main`.
- 🛡 **Обход CORS:** В мобильном приложении запросы идут через нативный `CapacitorHttp`, что исключает проблемы с CORS.

## 📱 Как установить (Для пользователей Android)

1. Перейдите в раздел **[Releases](https://github.com/hyevi/Kino-olxi/releases)** или **[Actions](https://github.com/hyevi/Kino-olxi/actions)** этого репозитория.
2. Скачайте последний файл `app-debug.apk`.
3. На вашем Android-устройстве разрешите установку приложений из неизвестных источников (в настройках браузера или файлового менеджера).
4. Установите и откройте **Кино Olxi**.
5. При первом запуске приложение попросит **API-токен**:
   - Перейдите в Telegram-бот **[@kinopoiskdev_bot](https://t.me/kinopoiskdev_bot)**.
   - Получите бесплатный токен и скопируйте его.
   - Вставьте токен в приложение и нажмите «Сохранить».
6. Введите ваше имя (для приветствия) и начинайте искать фильмы! 🍿
